Vision-Mate

An advanced React Native Expo application designed to assist visually impaired individuals. Integrates an Interactive Voice Assistant and real-time On-Device Obstacle Detector using C++ NCNN neural networks.

Download Center Read Setup Story

Core Subsystems

Interactive Voice AI

A voice-controlled virtual helper performing task automation including calling contacts, sending WhatsApp messages, battery checks, Google searches, and reverse geocoding location reporting.

On-Device Edge AI

Uses high-performance NCNN framework to load YOLOv8n object detection model locally. No cloud latency. Works fully offline in millisecond response times.

Obstacle Classifier

Identifies potholes, speed breakers, unpaved roads, and generic objects. Provides instant localized audio feedback like "Pothole ahead, move carefully".

Maps & Navigation

Links directly with Google Maps walking mode. Automatically triggers environmental camera scanning upon returning to the assistant workspace.

Setup Journey

Follow the scroll-revealed timeline to configure and run the VisionMate ecosystem from source code to your mobile device.

PHASE 01

Preparing Prerequisites

Before beginning, compile your laptop and phone configurations. Ensure you have the following ready:

  • Node.js: LTS version 18.x or higher installed.
  • Expo Developer Account: Free registration on expo.dev.
  • Android Phone: Connect your computer and mobile phone to the same Wi-Fi network (only required for hot reloading dev builds).
PHASE 02

Environment Setup & Installation

Extract the project code directory and launch your terminal console. Run the package commands to set up laptop dependencies:

# Install node package modules
npm install

# Install Expo Application Services (EAS) CLI globally
npm install -g eas-cli

# Securely login to your expo dev environment
npx eas-cli login
PHASE 03

Building Standalone Application (Option A)

Compiles a fully independent APK using Expo's cloud compiler. This does not require your laptop to remain running or active after installation.

# Trigger Android cloud build profile for preview release
npx eas-cli build --platform android --profile preview

Wait 5 to 15 minutes for compilation. Once completed, download the APK by clicking the URL generated or scan the printed terminal QR Code.

PHASE 04

Live Development Client (Option B)

If you want to modify code and see changes in real-time, build a custom developer container first, then launch Metro Bundler:

# Step B1: Compile custom development client APK
npx eas-cli build --platform android --profile development

# Step B2: Install downloaded APK, then launch local bundler server
npx expo start
CRITICAL WARNING: Standard Expo Go downloaded from the Play Store will crash! The NCNN C++ obstacle detection framework requires custom native modules compiled via these EAS workflows.
PHASE 05

Mobile Client Installation & Permissions

Install the downloaded APK on your Android phone (bypass Google Play Protect warning if prompted). Launch the app and grant these crucial hardware permissions:

  • Audio Recording: Used by the Speech-to-Text module to register voice commands.
  • Camera Access: Allows YOLOv8 model to scan physical environments.
  • GPS / Location: Performs reverse geocoding for navigation commands.
  • Contacts: Retrives system numbers to trigger dialing calls.
PHASE 06

System Operation & Commands

Once active, the interface blacks out (conserving blind user battery). Trigger features by speaking these vocal prompts:

Prompt Trigger Functional Action Taken
"Obstacle detection" Activates back camera and overlay scans green walking lanes.
"Where am I?" Speaks geocoded local road/city name details.
"Call [Name]" Matches name in contacts list and dials number.
"Navigate to [Place]" Opens walking route directly inside Google Maps.
